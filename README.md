## 🎯 What Does Mathboard Do?

Mathboard is packed with powerful features that transform how you interact with mathematics:

### 📝 Handwriting to LaTeX Conversion

Write math problems by hand, just like you would on paper. Mathboard uses a smart vision model (running locally on your computer) to recognize your handwriting and convert it to LaTeX - the professional mathematical notation language. This means you can write naturally and see beautiful, clean mathematical expressions appear instantly.

### 📊 3D Linear Algebra Grapher

Understand how neural networks work by seeing them in action. Mathboard shows every layer of a neural network as actual matrix multiplication, making the mathematics behind machine learning visible and clear. You'll see exactly how data flows through the network and transforms at each step.

## 🎓 How to Use Mathboard

### Using the Whiteboard

- **Write:** Use your mouse, stylus, or finger to write math expressions
- **Erase:** Look for the eraser tool in the toolbar
- **Clear:** Use the "Clear All" button to start fresh
- **Change Color:** Pick different colors for different parts of your work

### Converting to LaTeX

1. Write a math expression (like `2x + 3 = 7`)
2. Click the "Convert" button (looks like a magic wand)
3. Mathboard instantly shows the LaTeX version on the screen
4. Copy the LaTeX code or download it for use in other documents

### Exploring 3D Graphs

1. Click the "3D Grapher" tab at the top
2. Type in an equation or vector expression
3. Use your mouse to rotate the view (click and drag)
4. Scroll to zoom in and out
5. Use the grid and axes to understand spatial relationships

### Watching Neural Networks

1. Click the "Neural Network" tab
2. Load a sample network or create your own
3. Press "Play" to watch data flow through the network
4. Observe how each layer performs matrix multiplication
5. Adjust layer sizes and watch the dimensions change

## 🛠️ Troubleshooting Common Issues

### Handwriting Not Recognized?

- Make sure you're writing in the designated writing area
- Try writing larger and with more spacing
- Check that your touchscreen or tablet is properly connected
- Restart the application if recognition becomes slow

### 3D Graphics Running Slowly?

- Close other applications that use a lot of memory
- Lower the graphics quality settings in the preferences menu
- Update your graphics drivers from your computer manufacturer's website

### LaTeX Output Looks Wrong?

- Double-check your original handwriting
- Use proper math notation (like `^` for powers, `/` for fractions)
- Try separating long expressions into smaller parts
